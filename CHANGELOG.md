# Changelog

## [0.1.0] - 2026-10-25

### Added

- Rename files and folders to kebab, snake, caps, Pascal, or camel case
- Convert character case with Unicode simple mappings
- Transliterate Russian Cyrillic to ICAO Latin
- Preserve file extensions, dotfile prefixes, and existing destination files
- Install the plugin through Yazi or a Home Manager module
