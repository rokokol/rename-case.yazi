# Assets

`case.lua` contains data generated from the Unicode Character Database. The locked nixpkgs input supplies `UnicodeData.txt` through `unicode-character-database`

Unicode, Inc. provides the data under the [Unicode License v3](https://www.unicode.org/license.txt). [LICENSE](LICENSE) includes the required notice

The transliteration source is `translit/icao.json`. It preserves the Russian mappings from the original plugin and follows ICAO Doc 9303
